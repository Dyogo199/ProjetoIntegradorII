# Bookstore Relational Database Model

This snapshot was consolidated from the former `ProjetoIntegradorII_Unidade03` repository.

It contains a small relational database exercise for a bookstore, with `produtos` and `pedidos` tables, sample inserts, a foreign-key relationship and basic queries.

## Contents

- `livraria.sql` — schema, sample records and `SELECT` statements.

## Database Scope

The script uses `AUTO_INCREMENT` syntax and is closest to MySQL/MariaDB. Other relational database systems may require syntax adjustments.

## Historical Context

Preserved as part of the evolution of Projeto Integrador II.
