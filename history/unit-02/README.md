# Gestão Eficiente de Tarefas em Ambientes de Trabalho

Este snapshot foi consolidado a partir do antigo repositório `ProjetoIntegradorIIUnidade02`.

A etapa implementa uma aplicação web de gestão de tarefas usando HTML5, CSS3 e Vue.js 3 via CDN. O protótipo permite cadastrar tarefas, definir prioridade, listar os itens de forma reativa e removê-los.

## Funcionalidades

- cadastro de tarefas;
- prioridades baixa, média e alta;
- atualização reativa da lista;
- remoção de tarefas;
- interface responsiva.

## Arquivos

- `index.html` — estrutura da aplicação e integração com Vue.js;
- `style.css` — layout e responsividade;
- `app.js` — estado e operações da lista de tarefas.

## Execução

Abra `index.html` em um navegador com acesso à internet para carregar Vue.js pelo CDN.
