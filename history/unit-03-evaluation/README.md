# University Library Database Exercise

This snapshot was consolidated from the former `ProjetoIntegradorII_Unidade03_Avalia-o` repository.

The SQL exercise models a university-library domain with users, books, loans, reservations and fines. It also includes a trigger that returns a book to `disponivel` status when a real return date is recorded.

## Contents

- `biblioteca.sql` — MySQL-oriented schema, relationships, trigger, sample data and basic queries.

## Scope

This is a database-modeling exercise rather than a complete library-management application. No application layer, API, authentication or user interface is included in this snapshot.

## Historical Context

Preserved as part of the evolution of Projeto Integrador II.
